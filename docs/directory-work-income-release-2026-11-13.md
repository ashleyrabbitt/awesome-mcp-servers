# AI Superpower: directory, learning and work sample release

## Shipped experience

The directory now starts with task search, then optional filters and compact cards. Active filters can be removed individually. Existing saved stacks, comparison selections, remote search, review labels and affiliate routing remain in use. Publisher promotion moves below discovery results.

The shared visual system retains the forest-green, cream, lime and lavender brand, with bolder editorial hierarchy, consistent rounded cards, an original photographic-style hero and code-rendered step graphics. The homepage, navigation and footer connect the new destinations.

New routes:
- `/work-and-income`: career, work samples and small service paths.
- `/work-sample-builder`: local draft, fictional example, input validation, live case study preview, Markdown/text downloads and copy/clear controls.
- `/ai-career-guide`: practical samples for six roles, plus relevant JobCoach resources.
- `/ai-service-ideas`: three bounded pilot ideas with deliverables, review checkpoints and scope exclusions; relevant Descript referral uses the existing approved destination and disclosure.
- `/events`: four sourced upcoming events, our workshop links and SouthFLAI. Expired entries move into a past-event section when the page renders.
- `/learning-picks`: six paths chosen by the result the learner wants to make.

Three new news briefs cover ChatGPT Wallet (OpenAI, November 13), Figma 3D transforms open beta (Figma, November 12) and multi-user agent coordination research (Anthropic, November 11). Each preserves announcement/publication dates, links the primary source and separates interpretation from source claims. A Design & tech topic is now available.

The Work Sample Builder is the first pocket product because existing pages already cover task selection, agent planning and workflow practice. It closes the gap between doing an exercise and showing evidence of skill. This is an editorial product hypothesis, not validated demand. No vacancy board, earnings promises or fabricated client outcomes were added.

## Measurement and next opportunities

`work_sample_action` records only fixed actions (`example`, `download_md`, `download_txt`, `copy`) and the public page path. It respects the existing privacy controls. No entered text or generated case study content is included. A download event means a download was prepared, not that a job or sale occurred.

1. Observe builder visits, completed downloads and relevant working-session interest before adding payment or account requirements. Pair usage with a few voluntary conversations about whether the output helps.
2. If users complete samples and ask how to offer the work, build a Client Pilot Brief: buyer, deliverable, permitted inputs, deadline, revisions, acceptance and user-chosen fee. Keep it separate from the existing opportunity finder.
3. Add evidence-led case studies from actual workshop participants with permission. They will be more useful than additional generic AI tips.
4. Continue pricing verification and normalize duplicate catalog category labels (for example Browser Automation / Browser automation) across stored records and search, not only in the visible dropdown.
5. Keep jobs as a focused career-resource path connected to JobCoach until a dependable vacancy source and expiry process exist. AI Superpower should demonstrate useful skills; AI Side Hustle and Wealth Experiment supply deeper business-development guidance.
