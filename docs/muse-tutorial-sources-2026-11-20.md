## Editorial scope

This guide covers Meta’s consumer/personal Muse agent at muse.ai, matching the user’s recent context about Muse alongside dot, Claude Duet and Grok Bot. It does not cover unrelated Chrome sidebar tools with similar names or Muse Code. The guide uses public primary-source documentation and original practice prompts. The five-vendor workshop research and launch-brief exercise is proposed instruction, not a claim that Muse completed an observed hands-on trial. No accounts were connected or changed for this research.

The article has approximately 2,455 words across the body and FAQs, ten numbered steps, seven reusable prompts, a troubleshooting table, and four authentic provider-published images. Existing editorial rendering supplies canonical metadata, BlogPosting schema, RSS and sitemap entries. The hero has a post-scoped CSS override so the original panoramic screenshot is fully visible; the shared renderer is unchanged.
