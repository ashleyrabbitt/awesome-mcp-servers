# AI Superpower — useful tool practice pack
Reviewed November 11, 2026 · https://aisuperpower.cc
These are fictional practice inputs, not product test results.

## 1. Client-request tracker
Brief: build a request tracker with customer and owner roles. Fields: request ID, customer ID, title, description, status, created date. Statuses: New, Reviewing, Done. Customers see only their own requests; owner sees all and updates status. No live payments or emails.

Checks:
- [ ] Request survives refresh and sign-out.
- [ ] Two customers cannot access one another’s records.
- [ ] Owner update appears in customer view.
- [ ] Missing fields and failed saves are explained.
- [ ] Keyboard and narrow-screen paths work.
- [ ] Ownership, costs, export and recovery are documented.

## 2. Product walkthrough
Viewer: a first-time customer.
Outcome: submit a request and find its status.
Sequence: show completed result → submit sample request → owner updates status → customer sees update → try the sample workflow.

Checks:
- [ ] No private information or notifications.
- [ ] Captions match the words and screen action.
- [ ] Text stays readable on a phone.
- [ ] Export opens and destination link works.
- [ ] No invented customer results or savings.

## 3. Focused newsletter
Audience: independent consultants.
Promise: one practical AI workflow each week.
Issue: turn a meeting note into a clear action list.
Practice input: Maya will draft the invitation. Leo cannot commit to a review date until he sees the draft. A $300 budget was proposed but not approved.
Expected: Maya owns the draft; Leo’s date remains unconfirmed; $300 remains a proposal.

Checks:
- [ ] Original explanation and sources.
- [ ] One useful next action.
- [ ] Relevant affiliate disclosures.
- [ ] Signup, confirmation, links and unsubscribe checked.
- [ ] Record confirmed subscribers and actual clicks separately.

## 4. Voice assistant pilot
Use a fictional business and an approved FAQ. Test: known question; missing fact; interruption; corrected name/number; human handoff; unavailable destination.

Record for every case: input, expected behavior, actual behavior, source/transcript, reviewer, cost, pass/revise/stop.
No live customer calls, bookings, payments or outgoing messages are authorized by this template.

## 5. Compare and merge model answers
Prompt: create a final draft from the candidate responses using only the approved source pack for facts. Keep source IDs. Do not decide truth by majority vote. Separate conflicts and unknowns. Return the final draft, source ledger and unresolved questions.
