# Weekly Growth Decision Brief

**A reusable Grok Bot setup for a founder’s weekly growth review.** Version 1.0 · October 19, 2026 · Created for Ashley Kays / Waymaker.

Bring two comparable weeks of aggregate results. Leave with up to three evidence-backed observations and three useful next checks. This kit contains the complete Bot instructions, onboarding, a sample CSV, an example brief, and a practical evaluation checklist.

## Install in Grok Bot

1. In an account with Bot access, create a new Bot named **Weekly Growth Decision Brief**.
2. Set its description to: “Turns approved weekly growth exports into a concise decision brief with traceable calculations, data-quality flags, and three next checks.”
3. Paste the complete contents of `BOT-INSTRUCTIONS.txt` into the Bot’s instructions, or give them to the Bot and ask it to adopt them as its reusable role and workflow. Check the saved configuration before proceeding.
4. Start with the onboarding message below. Use the fictional sample files first; no app connections are necessary.
5. Compare the result with `EXAMPLE-BRIEF.md` and run the cases in `EVALUATION-CHECKLIST.md`. These are acceptance criteria, not claims that Grok has passed them.
6. To share, use the Bot’s Share menu → Create template (older interfaces may say Share as Template). Inspect View template details, remove private material, choose the intended audience, and publish using the actual available controls. Copy and test the resulting x.ai preview link. The reusable file here is not itself a native x.ai template link.

## Onboarding message to paste

Prepare my first Weekly Growth Decision Brief. Objective: [outcome]. Primary metric and definition: [definition]. Current period and comparison period: [dates, timezone, complete/partial]. Approved inputs: [files]. Attribution window and currency: [details]. Changes or exclusions: [notes]. Reviewer: [name or role]. Capacity this week: [hours]. First validate the inputs. Draft the brief here; do not change campaigns, budgets, records, or schedules.

## Try the fictional example

Use `sample-growth.csv` with `SAMPLE-CONTEXT.md`. All names, metrics and business situations are illustrative. The example is deliberately modest: total qualified leads stayed flat while paid-search efficiency worsened. The correct next step is an investigation, not an automatic budget change.

## Make it your own

Replace the sample with an aggregate export. Keep period boundaries, metric definitions, timezone and source ownership visible. If your columns differ, let the Bot propose a mapping and review it. Do not supply customer names or email addresses when channel totals are enough.

Use the brief manually until it is consistently useful. If you later want a routine, specify its source, schedule, timezone, destination and reviewer, and verify that the platform actually created it. Review connected-account permissions separately from the template.
